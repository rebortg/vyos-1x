    <div class="command-tags">
      <span class="command-tag multi">multivalue</span>
    </div>
  </div>
</dt>
  

<dd>

Protocols for which local conntrack entries will be synced

| Value | Help |
|-------|------|
| `dccp` |  Sync Datagram Congestion Control Protocol entries |
| `sctp` |  Sync Stream Control Transmission Protocol entries |
| `icmp6` |  Sync IPv6 Internet Control Message Protocol entries |
| `icmp` |  Sync Internet Control Message Protocol entries |
| `udp` |  Sync User Datagram Protocol entries |
| `tcp` |  Sync Transmission Control Protocol entries |

constraint error message: Allowed protocols: tcp udp icmp or sctp



</dd>
</dl>
