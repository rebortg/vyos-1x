      <span class="command-tag single">singlevalue</span>
    </div>
  </div>
</dt>
  

<dd>
<span class="command-tag default">default: static</span>

Specify the running mode of the rule

| Value | Help |
|-------|------|
| `interface` |  Forward Neighbor Solicitation message through specified interface |
| `auto` |  Check for a matching route in /proc/net/ipv6_route |
| `static` |  Immediately answer any Neighbor Solicitation Messages |

constraint error message: Mode must be either one of: static, auto or interface



</dd>
